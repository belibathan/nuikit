# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep feedback about the work, and no harassment of any kind. Roleplay servers can be competitive; this repo isn't.

Report problems privately by opening a [security advisory](https://github.com/belibathan/nuikit/security/advisories/new) marked "conduct", and maintainers will respond.
