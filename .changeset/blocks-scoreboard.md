A scoreboard block: `npm create nuikit@latest my-scoreboard -- -t scoreboard` shows who's online with server IDs, jobs and ping, a search, how full the server is, and which activities can start given who's on duty (jobs come from one `Config.job` function with ready-made Qbox, QBCore and ESX versions). Also in the registry (`…/r/scoreboard.json`).
