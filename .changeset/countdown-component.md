Registry: new `countdown` component (`npx shadcn add https://nuikit.vercel.app/r/countdown.json`): tabular `mm:ss` (`h:mm:ss` past an hour), a label, a line that drains, `warnAt` with a warning or destructive tone, a done state, sizes up to a full-screen clock, theme or game surface. Driven by Lua's `seconds`, or running on its own (`duration`) with `onComplete` fired from a timer. No package changes.
