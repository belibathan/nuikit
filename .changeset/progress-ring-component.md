Registry: new `progress-ring` component (`npx shadcn add https://nuikit.vercel.app/r/progress-ring.json`), the round half of the `progress` intent. A level (`value`/`max`) or a timed run (`duration`) whose `onComplete` fires from a timer, never an animation event, so it finishes with motion off. Label, percentage or any centre, status tones, a game or theme track, three sizes, a cancel hint. No package changes.
