Registry: new `key-prompt` component (`npx shadcn add https://nuikit.vercel.app/r/key-prompt.json`), the default look of the `prompt` intent. `KeyPrompt` (keys or a combination, label, description, icon, hold-to-confirm driven by `progress` from Lua or by pointer and key when the page has focus, active, disabled, panel or HUD surface) and `KeyPromptStack` (any edge), plus `parseKeyText()` for "[E] - Open garage" strings. It supersedes `key-hint`, which is unchanged. No package changes.
