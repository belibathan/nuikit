`vital-chip` display modes: `display` = pill (icon, name, value), value (icon, value), icon (the level as fill) or expand (opens to the pill on a change, settles after `--nk-rest-delay`); theme default `--nk-vital-display`. A chip that opens in a new `VitalChip.Row` pushes its neighbours, collapses them to icons or floats over them (`neighbours`, theme default `--nk-vital-neighbours`). `format` sets the value text.
