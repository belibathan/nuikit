# Changelog

Each package keeps its own changelog, generated by changesets:

- [`packages/core/CHANGELOG.md`](packages/core/CHANGELOG.md) (`nuikit-core`)
- [`packages/vite/CHANGELOG.md`](packages/vite/CHANGELOG.md) (`vite-plugin-nuikit`)
- [`packages/create-nuikit/CHANGELOG.md`](packages/create-nuikit/CHANGELOG.md) (`create-nuikit`)
- [`packages/cli/CHANGELOG.md`](packages/cli/CHANGELOG.md) (`nuikit`, not on npm yet)

Release notes for the kit as a whole (systems, overrides, adapters, the zips) are in
[`docs/releases/`](docs/releases/), one file per version.
