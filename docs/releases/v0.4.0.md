The whole kit. One `nuikit.zip` gives a Qbox server one design system: every screen is stock shadcn/ui, coloured by a single TweakCN theme and proportioned by one set of rules ([docs/design.md](https://github.com/belibathan/nuikit/blob/main/docs/design.md)). Tested in game on Qbox (ox_lib 3.40.3, qbx_medical, pma-voice, ox_inventory).

**`[nuikit]/` systems**
- `nuikit`: the server theme (`theme.css`)
- `nuikit_hud` (replaces qbx_hud) and `nuikit_stress` (keeps stress)
- `nuikit_pause`: Esc pause menu; Map, Settings and Key bindings return to it
- `nuikit_death`: death and last-stand screen, matched to qbx_medical
- `nuikit_loading`: loading screen with real progress, handing off to character select
- `nuikit_chat`: chat theme

**`overrides/`**: new interfaces, same Lua
ox_lib (and with it garages, mechanic, customs, vehicle shop, jobs, multicharacter), ox_inventory, ox_target, illenium-appearance, Renewed-Banking, mm_radio, qbx_scoreboard, qbx_idcard, qbx_taxijob, qbx_vehiclesales. Each is a clean-room implementation of that resource's UI protocol.

**Install**
1. Put `[nuikit]` in `resources/`. In server.cfg, after ox_lib, your framework and pma-voice:
   ```cfg
   ensure nuikit
   ensure [nuikit]
   stop qbx_hud
   stop loadscreen
   stop qbx_chat_theme
   ```
2. For each folder in `overrides/`, back up the real one, then copy ours over it (merge, don't replace).
3. Paste a TweakCN theme into `[nuikit]/nuikit/theme.css`.

Upgrading from 0.3.0: delete the old `nuikit`, `nuikit_hud` and `nuikit_stress` folders first (keep your `theme.css`).
