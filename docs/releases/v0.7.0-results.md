## Root causes found and fixes made (all on the live server; Lua diff in `patches/local-lua-patches.diff`)

**LOCAL FIX 1: empty ring after an HUD restart or start (A2 and A3).**
- **Root cause, proven by experiment:** `nuikit_hud/client/minimap.lua` called `RequestScaleformMovie('minimap')` to hide GTA's health and armour arcs. FiveM frees a resource's scaleform handles when it stops, and that unloads GTA's own radar movie. The ring then stays empty until the pause map rebuilds it.
- **Ruled out first:**
  - The mask texture's lifetime: moved into `nuikit`, still empty.
  - Swapping the mask on restart: skipped, still empty.
  - The big-map flick: disabled, still empty.
  - With only the scaleform request removed, the ring survives a restart.
- **Fix:**
  - The `nuikit` resource, which keeps running, holds the minimap scaleform for the session. It handles `nuikit:minimap:bars` (`SETUP_HEALTH_ARMOUR` 3 to hide, 1 to show), and the HUD triggers that instead of requesting the movie.
  - `nuikit` also owns the radar mask texture (`nuikit:minimap:mask`, applied only when it changes).
  - The HUD's own stop handler no longer resets the radar while `nuikit` is running, because `nuikit` already restores it a second after a real stop and does nothing on a restart. `nuikit` shows the bars again when it restores.
- **Verified in game:** restart → ring filled; stop → GTA radar with bars; start → ring filled. See `fix-a2-*.jpg` and `fix-a3-*.jpg`.

**LOCAL FIX 2: vehicle name over the speedo (A10).**
- The hide loop only ran once the vehicle loop had set `current`, which polls every 400 ms on foot. GTA starts the name the moment you sit.
- It now also checks `IsPedInAnyVehicle` and polls every 50 ms on foot (`nuikit_hud/client/main.lua`).

**A4 notes: the route outside the ring (not fixed).**
- The route layer ignores the `radarmasksm` texture and draws across the whole 1.41:1 radar box, which includes the hidden sides.
- `minimap_mask` placed over the hole doesn't clip it.
- `SetMinimapClipType(0)` makes blips pin to the box edges, which is worse; type 1 keeps blips on the ring.
- **Options:** an aspect closer to 1 (which trades back some squeeze), or find what clips the route. Enlarging the ring (the owner's idea) shrinks the overhang but doesn't remove it.

**Owner config changes (not nuikit code):**
- `radar = 'always'`. The owner wants it on foot too; proposed as the new default.
- `minimap.size = 15` (preset 12): "the map can be bigger".
- `setr qbx:motd ""` removes Qbox's welcome banner.
- ox_lib `resource/settings.lua` default `notification_position` changed `'top-right'` → `'top'`. The top-right ox_lib notifications drew **over the HUD's map, location and cash block** (`a1-notify-signal-overlaps-hud.jpg`). **Proper fix for the lead:** the ox_lib override keeps top-right notifications below the HUD stack, or the HUD reserves that area.

## UI changes (built from the repo, branch `local/owner-design` in the owner's clone, not pushed)

**UI CHANGE 1: one vital chip (commit 1696837, `systems/nuikit_hud/web`).**
- Health, armour, hunger, thirst and stress are all the same icon-only chip in both layouts; the labelled HEALTH and ARMOR pills are gone.
- The level is traced along the chip's own outline (`hud/outline.tsx`: the measured radius plus the `--nk-cut` chamfer). So it follows rounded, pill, circle and Signal's chamfered shapes.
- Voice and radio are chips of the same family.
- Owner asked: "the ring progress should bind to the edge / shape of the pill … health and armor … why wouldnt they just be like the others. we want to streamline."

**UI CHANGE 2: pause menu (commits 1696837 and 514a3a8, `systems/nuikit_pause/web`).**
- A full-height backdrop flush to the top, left and bottom edges (36rem, theme panel surface), with the menu in an inner column. Resume is the one primary bar, with 48px rows.
- The rest of the screen is clear for the focus camera, with key hints along the bottom.
- `pause:preview:frame` keeps the same contract; the open area is now about x 0.325, w 0.65 at 16:9.
- Owner: "thats pretty amazing. it looks great."

**UI CHANGE 3: pause map blips.** In progress at the time of writing; see the appendix when it lands.
