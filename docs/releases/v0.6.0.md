The kit grows into a full component set, and more of your server runs on it. Fifteen new components that will become the default look of every common UI request, seven screens rebuilt on them, nine starter blocks you can scaffold in one command, and a theme studio on the site. Tested in game on Qbox.

**Fixed**
- With the reduced-motion preference on (`/nuikit motion off`), ox_lib progress bars finished after about 0.1 s and the action failed. They now run their full duration, and a 0 ms run completes.

**Screens rebuilt on the shared components** (every request to the original resource is unchanged, verified request by request)
- ox_lib context and list menus and the progress bar, with whole-row list scrolling and visible bar tracks
- ox_target options, Renewed-Banking, illenium-appearance (clothing, barber, tattoos), qbx_taxijob meter, qbx_vehiclesales contract
- Death and loading screens on `meter` and `stat`

**Components** (`npx shadcn add`, previews on [/components](https://nuikit.vercel.app/components))
`notice` (+ stack), `form-field`, `confirm`, `key-prompt`, `progress-ring`, `countdown`, `money`, `item-slot`, `player-card`, `empty-state`, `skill-check`, a redesigned `radial-menu`, and new options for `menu-row`, `meter` (tones, timed mode) and `speedometer` (HUD tokens). `nui-toaster` and `task-progress` are deprecated in favour of `notice` and `meter` / `progress-ring`; both still work.

**Blocks: start a screen in one command**
```bash
npm create nuikit my-garage -- -t garage
```
`hud-minimal`, `death-screen`, `pause-menu`, `loading-screen`, `settings`, `scoreboard`, `garage`, `bank` and `job-menu`, each a full resource (Lua + UI) that imports the nuikit runtime. Garage, bank and job-menu check every action on the server. Live previews and install commands on [/blocks](https://nuikit.vercel.app/blocks).

**Site**
- [/theme](https://nuikit.vercel.app/theme): paste a TweakCN theme or tweak tokens, watch the kit update live, read the contrast check, download `theme.css`.
- The theme picker applies across the site, with the nuikit tokens.

**For developers**
- `nuikit check` recognises surfaces declared with `nk.surface` / `nk.open`.
- `pnpm sync` pulls in each component's dependencies and refuses undeclared imports.

**Install / upgrade**
1. Replace your `[nuikit]` folder with the new one (keep your `theme.css`). `ensure nuikit` before `ensure [nuikit]`.
2. For each folder in `overrides/`, back up the real one, then copy ours over it (merge, don't replace: `qbx_idcard` keeps using its own `flags/` and `badges/` images).
3. On Qbox with multicharacter, keep `externalShutdown = true` in `nuikit_loading/config.lua` if you had set it.

**Known issues**
- Death screen with qbx_medical + qbx_ambulancejob: the hold-to-respawn bar moves in 1-second steps, and the dead screen stays up during the hospital-bed treatment (about 20 s). Both predate this release; the fix is next.
- After several live restarts of `nuikit` / `nuikit_hud` while connected, the minimap can render blank until GTA's pause map is opened and closed (not seen on a fresh join).
