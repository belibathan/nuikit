# 0.7.0

Premium by default, unique by design, and the first pieces of "universal". Four identities you can start from
and a token system that reaches type, shape, surface, density and motion, not just colour; a compact flagship HUD;
every component on those tokens with compositor-only motion; `nuikit doctor` so a server can see its own
coverage; a one-line install; and the clean-room specs and spike resources that adapters (0.8) are built from.

**Not yet tested in game.** This release went out as one checkpoint so everyone works from one point. The
fixes from the first checkpoint test are browser- and CI-verified only; the retest list is in
[`v0.7.0-test.md`](../archive/v0.7.0-test.md#retest). Report what breaks and 0.7.1 follows.

**Identities and tokens 1.2** ([tokens](../tokens.md), [design v2](../archive/design-v2.md))
- Identity tokens: `--font-display` / `--font-numeric`, type ratio and weights, label case, border width, chamfers
  (`--nk-cut`), surface opacity / tint / gradient / edge, elevation, glow, density, easing and duration, the HUD
  style. A plain TweakCN paste is still the Graphite identity; everything v1 is unchanged.
- Four identities in `nuikit/themes/`: **Graphite** (default, compact and minimal), **Signal**, **Velvet**, **Vector**.
  Copy one to `theme.css`, `nuikit theme reload`.
- Component tokens (`--nk-panel-*`, `-row-*`, `-key-*`, `-chip-*`, `-meter-*`, `-gauge-*`, `-heading-*`, `-slab-*`)
  on every kit utility and registry component, each overridable in `theme.css`. Bundled OFL fonts.
- Motion: a ladder of durations, easings and springs derived from two inputs; two levels of reduced motion;
  `nuikit-core/motion` (springs, FLIP, timed runs) and `useSpring` / `useFlip` / `useIndicator`.
- The kit's `cn()` knows the `nk-*` utilities; a sync-drift gate and a class lint in CI; the
  [component contract](../design/contract.md).

**Flagship HUD v2** (`nuikit_hud`)
- `Config.layout = 'compact'` (default) or `'classic'`: round radar top right with the compass on its ring, zone and
  street under it, vitals pills with status dots, ammo `12 / 48`, a compact cluster with fuel arc and telltales.
  `Config.minimap.style = 'ring' | 'stock'`, auto-yield to minimap resources.
- Checkpoint fixes (unproven in game): overrides repaint on `nuikit theme reload` even when they started before
  `nuikit`; minimap after live restarts and `stop nuikit_hud`; GPS route and map aspect in the ring; ammo reserve
  with ox_inventory; first-person camera; stock-style overlap; `nuikit_pause` idle cost; Signal shapes; GTA's
  vehicle name under the cluster.

**Components and screens**
- Every registry component on the component tokens; slabs (item notice, prompt, timed progress, band);
  `countdown` drains on its own; `DateField` year/decade picker; `menu-row` progress and per-item colours;
  `meter` / `progress-ring` timed runs land on the true value; `form-field` `DateRangeField` + `TimeField`.
- ox_lib: notify, input dialog, alert, text UI, progress circle and skill check on the shared components, every
  POST identical; context menus on `menu-row`. Death: smooth hold bar, hidden during the qbx hospital bed.
  Loading: Qbox's own character menu detected (`externalShutdown`).
- Blocks: `interaction`, `shop`, `inventory`, `vehicle-shop`, `character-select` (14 in all), each server-checked;
  the existing blocks on the new components.

**Universal, step by step** ([architecture](../architecture.md))
- `nuikit doctor` ([doctor.md](../doctor.md)): framework, which adapter packs fit, every UI resource's status,
  conflicts, start order, theme contrast, with a next step each. `nuikit doctor json`.
- Install: `exec @nuikit/nuikit.cfg` in server.cfg; `nuikit-qbox.zip` / `-qbcore` / `-esx` / `-standalone`, each
  with a `server.cfg.snippet`; a txAdmin recipe for a new Qbox server (`install/`); `overrides.json` page hashes.
- Adapters (0.8): fifteen clean-room specs in `docs/adapters/`, spike resources and a 12-step in-game checklist
  in `bench/adapters/`, a replay harness.
- Design system in Figma: variables mirroring the tokens 1:1 in three tiers × four identities, primitives, and
  40 reference screens ([figma.md](../design/figma.md), [reference.md](../design/reference.md)).

**Install / upgrade**
1. Replace your `[nuikit]` folder with the new one (keep your `theme.css`). Replace `ensure nuikit` /
   `ensure [nuikit]` with `exec @nuikit/nuikit.cfg`.
2. For each folder in `overrides/`, back up the real one, then copy ours over it (merge, don't replace).
3. `nuikit doctor` in the server console tells you what's left.
