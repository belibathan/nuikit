# 0.7.0 checkpoint: in-game test

One session, one build: the latest `next-*` prerelease from `next/combined` (`lead/next`). The test passes when every
**Must** item passes. **Should** items can ship as known issues, and **Spikes** only measure, so they can't fail.

**Install (Qbox test server)**
1. Replace `[nuikit]` with the zip's folder. Keep your `theme.css`.
2. Copy every folder in `overrides/` over the real resource: ox_lib, ox_inventory, ox_target and the others.
3. In `nuikit_loading/config.lua`, remove any `externalShutdown` line.
4. Stop `qbx_hud`.
5. Run the client in dev mode (`+set moo 31337`) so `resmon` works.

## Must

| # | Area | Check |
|---|---|---|
| 1 | Death | Hold E to respawn: the bar fills smoothly. A quick release and re-press stays in step with qbx, and you respawn when it's full. A full release empties the bar on the next second. |
| 2 | Death | Last stand: the bleed-out line is red the whole time. In the hospital bed the screen is hidden. Esc doesn't open pause while down. |
| 3 | Loading | On Qbox multicharacter the screen holds on "Ready" until character select, with no timeout line in F8. |
| 4 | ox_lib input | Character creation birth date: header → year → 1990 in four clicks or fewer; typing `1990-06-15` works; years after 2006 are greyed out. |
| 5 | ox_lib | Notify, context menu (bars in their own colours), list menu, progress bar and circle (also with `/nuikit motion off`), skill check (hit, miss, wrong key), alert, text UI. |
| 6 | ox_target, banking, appearance, taxi, vehicle sales | Open each one once. They work as in 0.6.0. |
| 7 | HUD map | At your aspect ratio the radar fills the ring exactly (`Config.debug` prints both widths). Facing east reads 90°. The waypoint tag's arrow follows the waypoint. |
| 8 | HUD driving | Speed and RPM glide; gear shows R and N; shift lights work; telltales light without moving anything, including the handbrake (Space); fuel works with ox_fuel; seatbelt (B) works; qbx cruise (Y) shows the held speed. |
| 9 | HUD on foot | Vitals pills and dots appear on change and fade. Ammo shows only when armed. |
| 10 | HUD restore | `Config.minimap.style = 'stock'` puts back GTA's radar, and so does a live restart of `nuikit_hud`. |
| 11 | Identities | `nuikit theme reload` through Graphite, Signal, Velvet and Vector (copy `nuikit/themes/<name>.css` into `theme.css`). Each one repaints every open UI and reads at 1080p and 1440p. |
| 12 | Cost | `resmon`: `nuikit_hud` ≤ 0.02 ms on foot and ≤ 0.08 ms driving; every other nuikit resource ~0.00 ms when idle. Note `nuikit_pause` while it's closed. |
