# 0.7.0 checkpoint: in-game test

One session, one build: the latest `next-*` prerelease from `next/combined` (`lead/next`). The test passes when every
**Must** item passes. **Should** items can ship as known issues, and **Spikes** only measure, so they can't fail.

**Install (Qbox test server)**
1. Replace `[nuikit]` with the zip's folder. Keep your `theme.css`.
2. Copy every folder in `overrides/` over the real resource: ox_lib, ox_inventory, ox_target and the others.
3. In `nuikit_loading/config.lua`, remove any `externalShutdown` line.
4. Stop `qbx_hud`.
5. Run the client in dev mode (`+set moo 31337`) so `resmon` works.

## Retest (the fixes)

One build from the branch with the fixes. Same install. Each line is one check.

1. **Theme in overrides (F4).** Copy `nuikit/themes/signal.css` to `theme.css`, run `nuikit theme reload`: an open ox_lib
   context menu, a notify and ox_inventory repaint within a second. Reconnect: ox_lib notify and character select show
   Signal, not the old violet. Repeat with Graphite.
2. **Restart (F2).** In a vehicle with `style = 'ring'`: `restart nuikit_hud`. The ring fills without opening the pause map.
   Also restart while on foot, then get in a vehicle.
3. **Stop (F3).** `stop nuikit_hud`: within about a second GTA's square radar is back bottom left, with its health and
   armour bars. `start nuikit_hud` puts the ring back.
4. **GPS route (7b).** Set a waypoint and drive: the route line draws inside the ring.
5. **Aspect (note A).** The map inside the ring is no longer squeezed (a straight road crossing at right angles looks
   square). Check edge blips: they should sit on the ring, not at a box edge. `Config.debug` prints the hole and box widths.
6. **Ammo (F1).** `giveitem 1 WEAPON_PISTOL 1`, `giveitem 1 ammo-9 60`, equip: `12 / 48`; reload: the right number drops.
   Unarmed: no ammo readout.
7. **First person (F5).** In first person, open pause and the inventory: the camera doesn't spin.
8. **Stock style (F6).** `style = 'stock'`, on foot with low armour: the vitals don't overlap the money line.
9. **Cost (#12).** `resmon`: `nuikit_pause` closed ~0.01–0.02 ms (it must still check Esc every frame).
10. **Vehicle text (note C).** Entering a car no longer draws GTA's vehicle name over the speedometer.
11. **Signal shapes.** Under Signal the vitals dots and voice chip are chamfered like the pills.
