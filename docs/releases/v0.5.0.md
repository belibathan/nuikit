nuikit becomes a platform: the shared layer between scripts and screens on any FiveM server. One theme now reaches every UI live, players get accessibility settings, a written standard says how UIs share focus and Escape, and the pause menu, inventory and HUD show what's possible on it. Tested in game on Qbox.

**Theme engine (tokens v1)**
- Any shadcn / TweakCN theme is checked and completed: success, warning, info, HUD backing, `scrim`, health/armor/hunger/thirst/stress colours are derived when the theme doesn't set them, and contrast problems are printed in the server console.
- `nuikit theme reload` repaints every open UI live, overrides included. No restarts.
- Player preferences: `/nuikit scale 1.1`, `/nuikit motion off`, `/nuikit contrast on`, `/nuikit reset`.
- Published as a W3C design-tokens file and JSON Schema (`nuikit-core/tokens.json`). Spec: [docs/tokens.md](https://github.com/belibathan/nuikit/blob/main/docs/tokens.md).

**The standard (protocol v1)** — [docs/protocol.md](https://github.com/belibathan/nuikit/blob/main/docs/protocol.md)
- Versioned: resources declare `nuikit_protocol '1'`; the page and Lua negotiate version and capabilities.
- One Escape path across every resource; `NUI.open({ escape })`.
- Live values: `nk.stream(...)` in Lua and `follow` / `useFollow` on the page, for compasses, speedometers and gauges that glide at full frame rate from ~30 small messages a second.
- `nuikit check`: audits any resource against the standard. Every nuikit screen passes at the highest level, and CI keeps it there.

**Import nuikit like ox_lib**
```lua
dependency 'nuikit'
shared_script '@nuikit/init.lua'
```
The Lua runtime loads from the `nuikit` resource, so updating nuikit updates every resource that uses it. `nk` is the new name (`NUI` still works). New projects from `npm create nuikit` import it.

**Showcase screens**
- `nuikit_pause`: a camera that frames your character, a 3D map flown over the real game world, live key bindings, info pages and server stats. A flat menu for players with reduced motion or servers that set `Config.camera = false`. The camera always comes back on close, restart and death.
- `ox_inventory` override: panels on the screen edges and actions in a bottom bar. Every request to ox_inventory is unchanged.
- `nuikit_hud`: a themed minimap frame around GTA's radar with a gliding compass, gliding speed and RPM, hidden while the inventory is open. `Config.minimap.enabled = false` leaves GTA's radar alone.

**For developers**
- Registry components: `panel`, `menu-row`, `stat`, `meter`, `hud-chip` (`npx shadcn add`), and the kit utilities as `kit.css`.
- Site: [/components](https://nuikit.vercel.app/components), [/design](https://nuikit.vercel.app/design), [/coverage](https://nuikit.vercel.app/coverage).
- Host prototype (opt-in): renders many resources' UIs in one frame. Measured in game, FiveM already shares one browser process across all NUI frames, so it saves ~5 MB; it stays a convenience. [docs/host.md](https://github.com/belibathan/nuikit/blob/main/docs/host.md).

**Install / upgrade**
1. Replace your `[nuikit]` folder with the new one (keep your `theme.css`). In server.cfg, `ensure nuikit` before `ensure [nuikit]` (FiveM also starts `nuikit` first on its own now, since the screens depend on it).
2. For each folder in `overrides/`, back up the real one, then copy ours over it (merge, don't replace).
3. `nuikit theme` in the server console shows your theme's contrast check.

**Known issue**
- After several live restarts of `nuikit` / `nuikit_hud` while connected, the minimap can render blank until GTA's pause map is opened and closed. Not seen after a fresh join. A fix is next.
