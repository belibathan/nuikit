nuikit is now one design system for a whole FiveM server, built on ox_lib and themed by a single TweakCN paste. Tested in game on Qbox (ox_lib 3.40.3, pma-voice).

**Downloads**
- `nuikit-systems.zip`: the `[nuikit]` folder: `nuikit` (server theme), `nuikit_hud` (replaces qbx_hud / qb-hud), `nuikit_stress` (keeps Qbox/QBCore stress when the HUD is replaced).
- `nuikit-ox_lib.zip`: a free, open replacement for ox_lib's interface built from stock shadcn/ui. Replace `ox_lib/web/build`; no script changes.

**Install**
```cfg
ensure ox_lib
ensure [qbx]
ensure pma-voice
ensure nuikit
ensure [nuikit]
```
Paste any TweakCN theme into `nuikit/theme.css`.

**Packages (npm 0.3.0)**
- Surfaces: client-wide focus, layers and Escape order across resources (`NUI.surface`, `<Surface>`).
- Framework bridge: one player shape for Qbox, QBCore, ESX and standalone (`usePlayer()`).
- Server theming, `nuikit:ready` handshake, full TweakCN pastes with font `@import`s.
