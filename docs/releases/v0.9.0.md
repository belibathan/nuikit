# 0.9.0

The system, the adoption surface, and the owner's design pass. One token language generates every lever, one API
spec names every call, one layout model places every screen, and installing or upgrading is a console command.

**Not seen in game as a whole.** The owner's checkpoint ([v0.9.0-test.md](v0.9.0-test.md)) covered the Qbox
server; the list at the end says what is still unproven.

## The system

- **Token language** ([tokens.md](../tokens.md)): 529 levers generated from one spec, 33 components with declared
  anatomy, themes as values only. Tokens revision 2. Four themes: Default, Neon Pop, Flat, Square.
- **API spec** ([architecture.md](../architecture.md)): surfaces, intents and every domain as typed entries in one
  spec; `nk.<domain>.<verb>` on the Lua side, one `nuikit-core/<domain>` entry per domain, page and Lua events
  generated, `arsenal.json` generated. `nuikit check` flags undeclared `nk.*` paths and `nuikit:*` events.
- **Layout system** ([layout](../design/layout.md)): Screen, nine Zones, Region, Grid, a viewport table (ultrawide
  keeps the 16:9 box). HUD, pause and the host frame sit on it; devtools has a viewport picker.
- **Invariants** ([baseline.md](../design/baseline.md)): anatomy is theme-independent, one selection language, no
  page-drawn walls, no local concepts that shadow kit ones, every lever has a default and a reader. Each is a test
  or a `nuikit check` rule.

## Adoption surface

- `nuikit install`, `nuikit upgrade`, `nuikit uninstall` from the server console (override files are tracked,
  backed up, and only replaced when unchanged by you). An update check runs about 60 s after start and `nuikit
  doctor` prints it.
- `SHA256SUMS.txt` next to every release zip. [install.md](../install.md) per framework.
- `nuikit theme new <name> --from <theme>`: a values-only theme with every lever commented with its default.
- The site: a live preview, source and install per component and block; `/kit` lists the whole arsenal, generated.

## Design

- The sliding selection tile everywhere: menus, target, radial, inventory grid, scoreboard, Tabs, SegmentedControl.
- Stepper for every numeric control (pause settings, input intent, ox_lib input); smooth caret in every input.
- `[KEY]` tokens in any string render as keycaps (notify, confirm, prompt, progress, ox_lib text).
- Registry is the in-game version (speedometer, dial, vital chips, HUD and pause blocks), curated to 20 listed
  components, foundations first.
- Lean: no committed images (CI enforces it), one-off harnesses and unused synced components removed; the site is
  preview plus source.

- Selection jumped instead of gliding on pointer moves; radial wedge, inventory slots and target test: fixed.
- illenium action bar showed a hint and a button for Exit: one Exit now.
- ox_lib context titles: full emoji sequences, glyph moves to the icon column, no stray `|`; text UI defaults to
  bottom centre.
- Pause settings is a right-anchored sheet with scrolling sections.

- Flat flattens every tile; plate bleed at zero wall removed.

## Breaking changes

- **Themes removed:** arcade, street, studio, signal, vector, velvet, graphite. The `ink` alias is gone.
- **Components removed:** `hud-chip`, `vital`, `nui-menu` (`hud-chip` → `Chip`, `vital` → `VitalChip`, `nui-menu` → `Panel` + `MenuRowList`).
- **Tokens revision 2:** old `--nk-*` names are renamed per `packages/core/spec/migration.json`. Migrate with
  `node packages/core/scripts/migrate-levers.mjs <path>`.
- **Lua:** old names still work through `nk.legacy` (listed with `removeIn`) until 1.0; `nuikit check` warns
  (`arsenal/legacy`).

## Install

New server: [install.md](../install.md). Audit any resource without installing anything: `npx @belibathan/nuikit check <dir>`
(the CLI is now on npm as `nuikit`).

## Upgrade

1. Replace the `[nuikit]` folder with the new zip's; keep your theme file.
2. `restart nuikit`, then `nuikit upgrade` from the console, `refresh`, restart the resources it names.
3. Theme files: run the migration above, or start fresh with `nuikit theme new <name> --from default`.
4. `nuikit doctor` says what is left.
