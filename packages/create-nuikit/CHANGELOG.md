# create-nuikit

## 0.8.0

### Minor Changes

- 22148ce: Renderer packs (docs/intents.md §9). A resource that declares `nuikit_renderer 'notify'` (one line per intent) and ships a module built with `nuikitModule()` whose default export is a renderer (`defineReactRenderer`) or a record of them replaces nuikit's default renderer for that intent, still themed by the server's tokens and stacked by the runtime; the newest started pack wins a kind, a stopped one hands back, and a pack that fails to load falls back to the default with an F8 line. `nuikit-core/host`: `host.fetchModule()` loads a module script for its exports without mounting it, `hoist()` is exported. `npm create nuikit -- -t renderer-pack` scaffolds a pack with a notify renderer on `notice`, a browser preview and `/<name>_test`.

### Patch Changes

- eec33f8: Every block template on the v2 components and component tokens: money through `Money` / `formatMoney`, empty states through `EmptyState`, read-only rows (settings key hints, scoreboard activities, bank transactions) through `MenuRow readOnly`, the pause player card through `PlayerCard`, the pause and loading titles and the loading percent on the identity's display face (`nk-display`, `Stat size="display"`), captions on `nk-caption`, the death screen as text on the game (`nk-on-game`, no infinite pulse), the interaction options in a `Panel` with the hint as a `HudChip`, no width animations or raw durations. What each block sends to Lua is unchanged; the templates' server rules still pass their Lua 5.4 specs. Stills: `bank` takes `dialog`, `job-menu` takes `firing`.

## 0.7.0

### Minor Changes

- a63c345: A character-select block: `npm create nuikit@latest my-characters -- -t character-select` shows the player's characters at join (slots, a player card, Play, Delete with a confirm), where to spawn, and a create form. The server checks every choice: only the caller's own characters, only its own spawn points (it sends the coordinates), new characters with real names, an age of 18 to 100 and a listed gender in a free slot, deletes only from the character screen; last locations come from the server's own view of the player. It warns at start when a framework's own character screen is running. Also in the registry (`…/r/character-select.json`) and on `/blocks`.
- 014cfa9: An interaction block: `npm create nuikit@latest my-interaction -- -t interaction` gives a target eye (hold Left Alt, aim, and the options of what you aim at show; click for the cursor, or scroll and click) and "[E] Open the fridge" key prompts near places, with press or hold. Lua does the raycast and reads the keys; options and points marked `server = true` are checked again on the server (the option fits what was aimed at, the player is within reach by the server's own position, cooldowns). Also in the registry (`…/r/interaction.json`) and on `/blocks`.
- 50199a8: An inventory block: `npm create nuikit@latest my-inventory -- -t inventory` gives your pockets and a stash side by side with pointer-driven drag and drop (Shift drags half, Ctrl one), stacking and swapping, a tooltip, weight meters, use, and a hotbar (keys 1–5 and a strip on the game). It's a standalone inventory: the server keeps every container and checks every move (only your own pockets or a stash you stand at, real slots and counts, stacking only the same item, whole-stack swaps, weight on both sides) and refreshes everyone looking at a shared stash; it warns at start when ox_inventory or another inventory is running. Also in the registry (`…/r/inventory.json`) and on `/blocks`.
- 1cd8bca: A shop block: `npm create nuikit@latest my-shop -- -t shop` gives a catalogue by category with price and stock, a cart with steppers, cash or bank, and checkout with a confirm. The server keeps the prices and stock, checks every cart line and that the player is at the shop (OneSync), and moves money and items all or nothing (anything given is taken back and the money refunded if an item can't be carried); `Config.money` and `Config.items` hand them to Qbox, QBCore, ESX or ox_inventory. Also in the registry (`…/r/shop.json`) and on `/blocks`.
- 6e25537: A vehicle-shop block: `npm create nuikit@latest my-dealership -- -t vehicle-shop` gives a showroom with vehicles by category, a camera on a local preview car, stats, paint from swatches or any hex, test drives and buying with a confirm. The server keeps the prices, checks every purchase (the vehicle, the colour, the payment, the player at the showroom, one at a time), spawns the car itself with a unique plate, and refunds if the spawn or `Config.onBought` fails; test drives are spawned, timed and cleaned up by the server. Also in the registry (`…/r/vehicle-shop.json`) and on `/blocks`.
- db66763: Registry components read the design v2 component tokens (`--nk-panel-*`, `-row-*`, `-key-*`, `-chip-*`, `-meter-*`, `-gauge-*`, `-heading-*`, `-slab-*`) instead of fixed looks, so every identity restyles them without code changes.

  - **Slabs:** `notice` has an item add/remove slab (icon tile, name, delta) whose changes to the same item merge within 1.5 s; `key-prompt` is the prompt slab (key chip + verb) by default, takes no keys and wraps with `wrap`; `meter` has `variant="slab"`, the timed-progress slab (label, thin line, cancel key) that succeeds `task-progress`; new `band` for full-width states (incapacitated).
  - **Type:** countdown, money and stat heroes use `nk-display` in the numeric face; stat and meter labels use `nk-caption`.
  - **countdown** drains its line on its own between updates. **speedometer** draws gauge tokens (fill, redline, ticks, track width, numerals).
  - **form-field:** `DateField` has a picker that steps up to years and decades (as ox_lib's date row); date, range and time boxes size to their placeholder and digits; `TimeField` takes `icon` and `clearable`.
  - **menu-row:** `muted` (and ox's greys, `dark.3`) colours an uncoloured bar quietly.

  ox_lib's text UI uses key-prompt's no-keys and wrap. What scripts send and receive is unchanged.

- 682de8e: Identity tokens (tokens 1.1): type, shape, surface, density, motion and HUD style are tokens now, not just colour. `compileTheme` reads and derives `--brand`, `--font-display`, `--font-numeric`, `--nk-type-ratio`, the weights and tracking, `--nk-label-case`, `--nk-border-width`, `--nk-cut` (chamfered corners), `--nk-surface-opacity` / `-tint` / `-gradient` / `-edge`, `--nk-elevation`, `--nk-glow`, `--nk-density`, `--nk-ease`, `--nk-duration`, the HUD tokens and `--nk-row-indicator`, fills anything a theme leaves out (a plain TweakCN paste is the Graphite identity), and warns on floor violations (panel opacity under 0.92, HUD text over a white sky). Additive: every v1 name is unchanged. The kit utilities now read component tokens (`--nk-panel-*`, `--nk-row-*`, `--nk-key-*`, `--nk-chip-*`, `--nk-meter-*`, `--nk-gauge-*`, `--nk-heading-*`), each overridable in `theme.css`; new `nk-caption` utility. Four identities ship in `nuikit-core/themes` and the nuikit resource's `themes/`: Graphite (default), Signal, Velvet and Vector. Identity fonts (OFL, woff2) are bundled with every UI and served by the nuikit resource (`fonts/`).
- 677ab7e: Motion system (design v2 §5A, tokens 1.2). `compileTheme` derives a motion ladder from `--nk-duration` (`--nk-time-press` / `-hover` / `-base` / `-exit` / `-move` / `-modal` / `-screen` / `-ambient`, `--nk-stagger` and its cap), five easings and four springs (`--nk-spring-snap` / `-move` / `-soft` / `-pop`), from two new identity inputs, `--nk-motion-feel` (crisp, snap, smooth, stepped) and `--nk-spring-bounce`. Graphite is crisp, Signal snaps, Velvet glides with a slight bounce, Vector steps. Additive.

  Reduced motion now has two levels: a theme's `--nk-motion: 0` is off (as before), and the player's `reducedMotion` pref is "reduced" (`data-nk-motion="reduced"`): no movement, fades kept at most 100 ms. New `--nk-motion-move`. The prefs message is unchanged.

  New `nuikit-core/motion` entry (no dependencies, about 2 kB): springs sampled into Web Animations keyframes, retargeting with velocity, FLIP, timed runs, the selection indicator's key-repeat rule; `useSpring`, `useFlip` and `useIndicator` in `nuikit-core/react`.

  Kit: no text selection or image drag outside fields, themed scrollbars, selection, caret and placeholder; `nk-pop`, `nk-rise`, `nk-press`, `nk-stagger`, `nk-skeleton`, `nk-blink` and `nk-indicator`; keyboard and controller state (rows, tabs, toggles, focus) changes instantly. Components: `meter` and `progress-ring` timed runs and the `skill-check` needle are each one compositor animation (no per-frame JS or React renders); meter segments scale instead of resizing, and a critical meter blinks twice instead of pulsing forever. ox_lib's progress and skill check keep every request and timing.

### Patch Changes

- 31de54b: Bank's money dialog is the kit's Confirm with form-field rows (TextField for amount, recipient and note; Enter in a field still sends), and job-menu's fire confirm is the kit's Confirm (focus on "Keep them"). Both surfaces are now `escape = 'back'`: Escape closes the dialog first, then the menu, through nuikit. Escape typed in a bank field first moves to Cancel, since nuikit leaves Escape in a field to the field. What each sends to Lua is unchanged.
- 45561a7: Existing blocks on the new components: death-screen's clock is the kit's Countdown and its keys are KeyPrompts (the respawn hold fills the prompt's own line), pause-menu's Disconnect asks with the kit's Confirm (Escape closes the confirm first, then the menu), settings' sliders are form-field's SliderField (still sending once, when let go), and the demo template's "Open menu" hint is a KeyPrompt. What each sends to Lua is unchanged.
- 4d92fed: `cn()` knows the nk-_ kit: `lib/utils.ts` is generated from `kit.css`, so a kit utility removes the earlier stock classes that set its colour or type (`text-hud-foreground` before `nk-chip-active` no longer wins), and one type style (`nk-title`, `nk-label`, `nk-caption`, `nk-display`), surface (`nk-panel`, `nk-hud`, `nk-chip`, `nk-slab`) or anchor (`nk-anchor-_`) applies per element. Layout, shape and shadows merge as before. Existing shadcn projects can take it from the registry: `npx shadcn add https://nuikit.vercel.app/r/utils.json`.

## 0.6.0

### Minor Changes

- a97e831: A bank block: `npm create nuikit@latest my-bank -- -t bank` shows accounts, balances and recent transactions, with deposit, withdraw and transfer checked on the page and again on the server; a standalone example (cash, checking and savings per player) and `Config.money` for a framework's own cash and bank. Also in the registry (`…/r/bank.json`) and on `/blocks`.
- cfb8d9f: A garage block: `npm create nuikit@latest my-garage -- -t garage` lists your vehicles at a garage with fuel, engine and body, and takes them out, stores the one you're driving, or releases one from the impound, with a working standalone example (vehicles kept per player in a JSON file) and the lines to change for Qbox, QBCore or ESX. The server checks every request (your own vehicles only, at the garage, the vehicle read from the game), spawns and deletes vehicles itself so one can't come out twice, and refunds the impound fee if a release fails. Also in the registry (`…/r/garage.json`) and on `/blocks`.
- c280022: Start from a block: `npm create nuikit@latest my-hud -- -t hud-minimal` (or `-t death-screen`, or pick from a list) scaffolds a whole screen from the registry with its Lua (`@nuikit/init.lua`, `nk.surface`, `nk.stream`). The first two blocks are also in the registry (`npx shadcn add https://nuikit.vercel.app/r/hud-minimal.json`, `…/death-screen.json`). New projects now depend on the nuikit-core and vite-plugin-nuikit of the same release instead of 0.2.
- 6f5181b: A job-menu block: `npm create nuikit@latest my-jobs -- -t job-menu` gives a duty toggle and the job's actions, and for the boss a Staff tab with the job account, promote, demote, fire (with a confirm) and hire whoever is nearby. The server checks every request against the caller's own job and grade, never what the page says; a standalone example (jobs and grades in `config.lua`, who works where per player in a JSON file) and `Config.sync` to mirror changes into Qbox, QBCore or ESX. Also in the registry (`…/r/job-menu.json`) and on `/blocks`.
- 881cfbb: Two more blocks: `npm create nuikit@latest my-pause -- -t pause-menu` (Esc opens it in place of GTA's pause menu, with the game's map, settings and key bindings one click away and a confirm before Disconnect) and `-t loading-screen` (the real load progress phase by phase, tips, links, backgrounds and music, themed through the connection handover). Both are also in the registry (`…/r/pause-menu.json`, `…/r/loading-screen.json`).
- 0d46d01: A scoreboard block: `npm create nuikit@latest my-scoreboard -- -t scoreboard` shows who's online with server IDs, jobs and ping, a search, how full the server is, and which activities can start given who's on duty (jobs come from one `Config.job` function with ready-made Qbox, QBCore and ESX versions). Also in the registry (`…/r/scoreboard.json`).
- ffc9b4a: A settings block: `npm create nuikit@latest my-settings -- -t settings` gives players one panel of toggles, choices, sliders and key hints, saved on their PC and announced to your scripts, with nuikit's accessibility preferences (UI size, reduced motion, high contrast) built in. Also in the registry (`…/r/settings.json`).

## 0.5.0

### Minor Changes

- e9714e0: New projects start on the kit: the demo HUD, menu and confirm are built from the new `panel`, `menu-row`, `meter` and `hud-chip` registry components, and `index.css` carries the new kit utilities (`nk-panel-header-stack`, `nk-field`, `nk-anchor-*`, `nk-first-row`).
- 5d9eb9d: Import the Lua runtime like ox_lib: `dependency 'nuikit'` + `shared_script '@nuikit/init.lua'` loads it from the running `nuikit` resource, so updating nuikit updates every resource that uses it. `nk` is the new name (`NUI` stays the same table); the framework bridge loads on first use of `nk.player`. New projects from `create-nuikit` import it instead of carrying a copy of `nuikit.lua`. `nuikit check` accepts the import as the runtime.
